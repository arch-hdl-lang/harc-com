HARC verification language syntax highlighting for VSCode.

Install by copying this folder to your VSCode extensions directory
(`~/.vscode/extensions/harc-0.1.0/` on macOS/Linux,
`%USERPROFILE%\.vscode\extensions\harc-0.1.0\` on Windows) and
restarting VSCode, or by running:

    code --install-extension harc-0.1.0.vsix

after packaging with `vsce package`.

Sister extension: see `editors/vscode/` in arch-hdl-lang/arch-com for
the ARCH HDL highlighting (matching color conventions; both extensions
can be installed side by side).
