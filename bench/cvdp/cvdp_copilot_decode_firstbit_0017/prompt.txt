### **Inputs:**

- `Clk`: **1-bit clock signal**, toggling every **5 time units** (100MHz operation).
- `Rst`: **Active-high reset signal** to initialize the module.
- `In_Data`: **32-bit input bus** for data values.
- `In_Valid`: **Signal indicating valid input data**.

### **Outputs:**

- `Out_FirstBit`: **Position of the first set bit** (Binary or One-Hot encoded).
- `Out_Found`: **Indicates if a set bit was found**.
- `Out_Valid`: **Indicates valid output data**.
